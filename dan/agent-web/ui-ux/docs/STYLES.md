# UI-UX Pro Max - Style Reference

| ID | Style Category | Keywords | Best For | Implementation Checklist |
|----|----------------|----------|----------|--------------------------|
| 1 | Minimalism & Swiss Style | Clean, simple, spacious, functional | Enterprise apps, dashboards, SaaS | ☐ Grid-based layout, ☐ Typography hierarchy, ☐ No unnecessary decorations |
| 2 | Neumorphism | Soft UI, embossed, debossed, rounded | Health/wellness, meditation, fitness | ☐ Rounded corners 12-16px, ☐ Multiple shadow layers, ☐ Pastel colors |
| 3 | Glassmorphism | Frosted glass, transparent, blurred | Modern SaaS, financial dashboards | ☐ Backdrop-filter blur 10-20px, ☐ Translucent white, ☐ Vibrant background |
| 6 | Vibrant & Block-based | Bold, energetic, playful, blocks | Startups, creative agencies, gaming | ☐ Block layout with 48px+ gaps, ☐ Large typography 32px+, ☐ 4-6 vibrant colors |
| 19 | **Soft UI Evolution** | Evolved soft UI, better contrast, hybrid | Modern enterprise, SaaS, health/wellness | ☐ Improved contrast AA/AAA, ☐ Soft shadows, ☐ Border-radius 8-12px |
| 38 | Neubrutalism | Bold borders, black outlines, Gen Z | Gen Z brands, startups, Notion-style | ☐ Hard borders (2-4px), ☐ Hard offset shadows, ☐ High saturation colors |
| 39 | Bento Box Grid | Modular cards, asymmetric grid, Apple | Dashboards, product pages, feature showcases | ☐ Grid responsive, ☐ Card spans varied, ☐ Rounded corners 16-24px |
| 43 | AI-Native UI | Chatbot, conversational, streaming | AI products, chatbots, copilots | ☐ Chat layout responsive, ☐ Typing indicator smooth, ☐ Streaming text |
| 55 | Spatial UI (VisionOS) | Glass, depth, immersion, gaze | VR/AR, futuristic dashboards | ☐ Glass effect visible, ☐ Depth layers clear, ☐ Gaze-hover effects |
